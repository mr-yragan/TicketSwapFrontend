# TicketSwap Frontend

Это фронтенд для моего курсового проекта по перепродаже билетов.

Смысл приложения простой: пользователь может зарегистрироваться, выставить билет на продажу, купить билет у другого пользователя и следить за своими объявлениями и заказами. Отдельно есть роли для админа и организатора.

## Что есть в проекте

- регистрация, логин, подтверждение почты
- восстановление пароля
- 2FA
- страница со списком билетов
- поиск, фильтры и пагинация
- карточка и детальная страница билета
- создание объявления о продаже билета
- личный кабинет пользователя
- админка
- панель организатора

## Роли

### Обычный пользователь

Может:

- смотреть билеты
- покупать билеты
- выставлять свои билеты на продажу
- управлять профилем
- смотреть свои заказы, резервы и объявления

### Админ

Может:

- создавать организаторов
- смотреть журнал заказов
- смотреть журнал аудита

### Организатор

Может:

- управлять своими событиями
- проверять билеты вручную
- работать с очередями на подтверждение и перевыпуск

## Стек

- React
- Vite
- React Router
- Axios
- Tailwind CSS

## Как запустить локально

```bash
npm install
npm run dev
```

По умолчанию фронт стартует на:

```text
http://localhost:3000
```

## Важно по API

Фронт ожидает, что backend запущен на:

```text
http://localhost:8080
```

Прокси уже настроен через Vite, поэтому локально запросы идут через `/api`.

Если нужно поменять адрес API, можно использовать `.env`:

```env
VITE_API_URL=/api
```

## Структура проекта

Если совсем коротко:

- `src/pages` — страницы
- `src/components` — общие UI-компоненты
- `src/features` — фичи по зонам приложения
- `src/api` — работа с API
- `src/context` — контексты приложения
- `src/hooks` — общие хуки

## Что ещё важно

- мобильная версия тоже поддерживается
- часть поведения зависит от версии backend
- если на backend меняются контракты, фронт тоже нужно синхронизировать

---

Если коротко: это не лендинг, а рабочее приложение с ролями, покупкой билетов, модерацией и кабинетом для разных сценариев.
